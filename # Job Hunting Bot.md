
An automated job finder that searches and displays the latest engineering positions based on your keywords.

## Features
- Search jobs by keywords (e.g., "New Grad Software Engineering")
- View: Company, Date Posted, Position, Location, Apply Link
- Automated searches (hourly, every 2-3 hours, etc.)
- Clean, responsive interface

## How to Use
1. Visit [your-railway-app-url]
2. Enter your job search keywords
3. Set your preferred search frequency
4. View and apply to matching positions

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (FastAPI/Flask)
- Database: PostgreSQL
- Deployment: Railway
- Containerization: Docker
